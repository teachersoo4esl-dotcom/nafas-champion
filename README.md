# بطلة نافس | NAFAS Champion

## التشغيل
1. ثبتي Node.js 18+.
2. داخل مجلد المشروع: `npm install`
3. شغلي: `npm start`
4. واجهة الطالبات: `http://localhost:3000/`
5. لوحة المعلمة (لا يوجد رابط لها في واجهة الطالبات): `http://localhost:3000/teacher`

## حماية لوحة المعلمة
للتجربة المحلية فقط، الرمز الافتراضي هو: `NafasTeacher2026!`
قبل النشر، لا تستخدمي الرمز الافتراضي. عيّني متغير البيئة `ADMIN_PASSWORD` ورمز جلسة قوي `SESSION_SECRET`.
مثال macOS/Linux:
`ADMIN_PASSWORD='رمز-قوي' SESSION_SECRET='قيمة-عشوائية-طويلة' npm start`

للنشر عبر HTTPS غيّري `secure:false` إلى `secure:true` في إعداد cookie داخل `server.js`.

## تعديل الأسئلة
كل الأسئلة موجودة في ملف `questions.js` في مكان واحد: السؤال، الخيارات، الإجابة، المهارة، الاستراتيجية، التلميح، الزمن، النقاط، وتفسير المشتتات.

## ملاحظة الخصوصية
لوحة المعلمة محمية على الخادم بجلسة Admin، وواجهات API الخاصة بالنتائج ترفض الطلبات غير المصرح بها. إخفاء الرابط وحده ليس هو وسيلة الحماية.
